# SecAlert

A ticketing platform for Security Incident alerts

Roles:
* Admin: Adds users and sees all tickets
* User: Submits tickets and can see only their tickets

**Admin**
The administrative role allows for the user to add other users to the SecAlert system.
Admins have access to ALL tickets, and they can change the status of those tickets along with replying to the user that sent them

**Users**
The default user role is for normal employees. They can us SecAlert to submit tickets and see all the tickets they have sent in
